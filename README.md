One image summing up Friday 20 November 2026: 47 verified world-news stories — the Kyiv barrage, Cyclone Akvan, the Poland incursion and the global AI sell-off — laid out as a stacked-newspapers front page with a UTC timeline, a numbers strip, CLAIM/CONFIRMED proof tags on every lead and medium card, a dotted world map with numbered pins, and a DATE CHECK naming the stories that are *not* from this Friday, with their true dates. Every story happened or was first reported on that Friday; each was checked against its wire or outlet before it was drawn.

## Run it

```sh
python3 main.py
```

Copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or the repo directory when unset) and verifies the copy by sha256. Stdlib only — no third-party packages needed.
